# Duplicate and Missing Usage Events

Usage events should be checked against the authoritative source ledger before billing discrepancies are explained.

A duplicate event occurs when the observed stream contains repeated occurrences that are not supported by the authoritative ledger or the applicable event-processing rules.

A missing event occurs when an expected occurrence in the authoritative ledger is absent from the observed stream.

Detected duplicate or missing events do not, by themselves, establish the financial impact. The investigation must determine whether the affected events were billable and whether they were included in the invoice calculation.
